# Политика конфиденциальности мобильного приложения «Android Доктор» (`com.androiddoc.app`)

**Дата вступления в силу:** 8 ноября 2026 г.  
**Разработчик:** Andrew Tusar (`https://github.com/AndrewTusar`)

Настоящая Политика конфиденциальности описывает принципы обработки информации в мобильном приложении **«Android Доктор»** (пакет `com.androiddoc.app`).

---

## 1. Общие положения и назначение приложения
Приложение **«Android Доктор»** является локальной сервисной утилитой (инструментом) для диагностики состояния оперативной памяти, очистки временного кэша и настройки параметров Android-устройств (смартфонов, планшетов, ТВ-приставок) при их подключении по кабелю **USB OTG** или по домашней сети **Wi-Fi (протокол ADB)** с явного согласия владельца подключаемого устройства.

## 2. Отсутствие сбора персональных данных
Приложение **НЕ собирает, НЕ хранит и НЕ передаёт третьим лицам персональные данные пользователей**:
- Приложение **не требует регистрации** или создания учётной записи;
- Приложение **не запрашивает и не обрабатывает** ФИО, номера телефонов, адреса электронной почты, данные банковских карт, контакты телефонной книги (`READ_CONTACTS`), СМС-сообщения (`READ_SMS`), журнал вызовов (`READ_CALL_LOG`), точное местоположение (`ACCESS_FINE_LOCATION`), данные камеры или микрофона;
- Приложение **не имеет доступа** к личным фотографиям, видеозаписям и перепискам пользователя в мессенджерах.

Вся техническая информация об устройстве (объём свободной оперативной памяти ОЗУ, уровень заряда аккумулятора, версия ОС Android, список установленных пакетов) обрабатывается **исключительно локально на устройстве пользователя** в момент активного сеанса диагностики.

## 3. Запрашиваемые разрешения и цели их использования
Для выполнения своих функций приложение использует только минимально необходимые технические разрешения Android:
1. **`android.hardware.usb.host`** — для установления локального соединения со вторым Android-устройством по кабелю USB OTG (только после нажатия пользователем кнопки подтверждения доступа к USB).
2. **`android.permission.ACCESS_WIFI_STATE` / `ACCESS_NETWORK_STATE`** — для определения локального IP-адреса при поиске и подключении к Android TV приставкам в домашней локальной сети Wi-Fi.
3. **`android.permission.QUERY_ALL_PACKAGES`** — исключительно для локального формирования списка установленных приложений во вкладке «Перенос APK», чтобы пользователь мог по собственному желанию передать выбранное приложение с одного своего устройства на другое по кабелю или Wi-Fi.
4. **`android.permission.INTERNET`** — для отображения рекламных материалов партнёрской сети Яндекса (РСЯ) и выполнения обезличенных справочных запросов к модулю искусственного интеллекта по техническим названиям системных пакетов.

## 4. Сторонние сервисы и реклама
В приложении используются рекламные блоки **Рекламной сети Яндекса (РСЯ / Yandex Advertising Network)**. При показе рекламных объявлений сервисы ООО «Яндекс» могут обрабатывать обезличенные технические идентификаторы устройства в соответствии с [Политикой конфиденциальности Яндекса](https://yandex.ru/legal/confidential/).

## 5. Безопасность и возврат настроек
Все действия по оптимизации и ограничению фоновой активности приложений выполняются стандартными системными командами Android без использования Root-доступа и могут быть в любой момент отменены пользователем одной кнопкой («Вернуть заводские настройки») внутри приложения.
